AliTechGrid.com — Solution Intelligence + AI Collaboration Network
Build date: 2026-08-14

PURPOSE
This build presents AliTechGrid as a Canada-based, globally engaged Sovereign AI, education technology, institutional capability, collaboration, training and implementation organization. The website demonstrates working decision, document and collaboration experiences rather than functioning only as a brochure.

MAJOR CAPABILITIES
- AI Solution Intelligence: adaptive diagnostic, readiness scoring, Pilot / Strategic / Transform scenarios, SWOT, KPIs, roadmap and decision-document recommendations.
- Professional Document Studio: Business Plan, Business Case, Feasibility Study, Proposal, Draft MoU, Implementation Plan and Leadership Decision Brief with human-validation safeguards.
- FacultyOS: faculty, student and management intelligence pathways plus a privacy-first demo request workflow.
- AI Collaboration Network: organization + individual-professional pathways, Collaboration Match Preview, illustrative Opportunity Board and controlled Collaboration Profile workflow.
- Sovereign / Private AI: architecture, RAG, data residency, model governance, access controls and audit pathways.
- Training & Capacity: leadership, faculty, staff, workforce, Train-the-Trainer, Python/AI, cloud/AI and automation.
- Collaboration: proposed diploma/certificate pathways, curriculum modernization, Sovereign AI labs, applied research and industry collaboration.
- Consulting & Implementation: strategy, business case, feasibility, governance, architecture, pilots, implementation and evaluation.
- Credential Studio: public sample-only certificate experience; official issuance remains authenticated and controlled.
- AliTechGrid AI Guide: approved-content website guidance with no external public LLM/API key.

AI COLLABORATION NETWORK — LAUNCH MODEL
- Organizations and individual professionals can submit a short expression of interest.
- Required: full name, email, country/region, collaboration interest, description of need and contact consent.
- Optional: phone/WhatsApp and contribution details.
- The user receives a locally generated Collaboration Profile & Opportunity Summary with a request reference, preliminary AliTechGrid pathway and Print / Save PDF option.
- The public form does not automatically upload or save the entered information to an AliTechGrid website database.
- The user deliberately chooses whether to send the prepared request by email or WhatsApp.
- No public profile, network affiliation record, endorsement or partner status is created by submitting the form.
- Formal collaboration is represented only after review and appropriate agreement/authorization.

PRIVACY / SECURITY
- Public forms and previews run locally in the browser for the launch build.
- Users are instructed not to enter confidential, student, client or other sensitive information.
- Public Credential Studio certificates remain SAMPLE · NOT VALID.
- No reusable personal signature image is exposed in public certificate samples.
- No external generative-AI API key is embedded in the public website.

DEPLOYMENT
Upload the CONTENTS of this folder to the root of GitHub repository AliTechGridHQ/alitechgrid-com.
Do not upload the ZIP itself.
Connect the repository to a new Cloudflare Pages project, test the pages.dev preview, then attach alitechgrid.com and www.alitechgrid.com.
Do not change Zoho Mail MX/TXT records when connecting the website.
